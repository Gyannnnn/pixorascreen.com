## How to Use the Fake Virus Screen

The fake virus screen recreates four security warnings that most computer users have seen or heard of. Choose one, put it in fullscreen, and the device looks as if it has hit a real security problem, while it is only showing a web page.

1. Pick an alert style with the keys <kbd>1</kbd> to <kbd>4</kbd>, or from the gear icon's settings panel.
2. In the same panel, keep the siren on or switch it off. Sound starts only after you go fullscreen.
3. Press <kbd>F</kbd> or the Fullscreen button. The browser's tabs and address bar disappear.
4. Press <kbd>S</kbd> to mute or unmute the alarm, and <kbd>Esc</kbd> to end the simulation.

## The Four Alert Styles

### Chrome "Deceptive site ahead" (key 1)

A red full-page warning modeled on the one Google Chrome shows when Safe Browsing flags a site for phishing. The real warning appears before a dangerous page loads, and its main button takes you back to safety.

### Microsoft Defender SmartScreen (key 2)

A blocked-site page in the style of Microsoft Edge's SmartScreen, which stops sites and downloads that have been reported as unsafe.

### Windows Security dashboard (key 3)

A mock Windows Security app with a scan progress bar, a threat card, and a pop-up notification, the most "busy" of the four, so it suits video scenes where something needs to happen on screen.

### WannaCry ransom screen (key 4)

A replica of the "Wana Decrypt0r 2.0" window from the 2017 WannaCry outbreak, with countdown timers and a payment panel. The address shown is made up, and the buttons do nothing but display a message.

## How to Tell a Fake Warning From a Real One

The same tricks that make this page convincing are used by real scams, so it is worth knowing the signs:

- **Real browser warnings never ask you to call a phone number.** A full-screen alert with a support number, a siren, or a countdown is a tech-support scam.
- **Antivirus software does not run inside a web page.** A "scan" that appears in a browser tab, finding dozens of viruses in seconds, is fake.
- **Nothing legitimate asks for gift cards or cryptocurrency.** Microsoft, Google, and Apple never ask for payment to remove a warning.
- **Closing the tab is enough.** If a scam page will not close, press <kbd>Ctrl</kbd> + <kbd>W</kbd>, or force-quit the browser with Task Manager on Windows or <kbd>Cmd</kbd> + <kbd>Option</kbd> + <kbd>Esc</kbd> on a Mac, and do not restore the previous session when you reopen it.

Real ransomware arrives as a program, not a web page. If files on your computer really have been encrypted, disconnect it from the network and get professional help, rather than paying.
