## How the Hacker Typer Works

The hacker typer looks like a code editor in a dark room. Press any keys, mash them at random if you like, and lines of serious-looking code appear on the screen as if you were writing them at superhuman speed. It is the screen behind every movie hacker, made into something you can control.

1. Press <kbd>F</kbd> for fullscreen. The editor fills the display and the browser disappears.
2. Type anything. Each key press adds the next few characters of the current code file.
3. Press <kbd>1</kbd>, <kbd>2</kbd>, or <kbd>3</kbd> to switch between three files: `cve_exploit.c`, `sniffer.py`, and `brute_force.go`.
4. Press <kbd>Tab</kbd> or <kbd>Enter</kbd> for the finale: an "Access Granted" message on screen.
5. Press <kbd>Esc</kbd> to stop.

## Settings

Outside fullscreen, the settings above the editor let you shape the effect:

- **Theme:** VS Code Dark, Monokai Retro, Amber Terminal, or Matrix Green.
- **Speed:** 1 to 15 characters per key press.
- **MX Switch:** the sound of each key, Blue Switch, Brown Switch, Typewriter, or Muted.

In fullscreen, <kbd>A</kbd> starts autopilot so the code types itself, and <kbd>S</kbd> toggles the keyboard sound.

## Ideas for Using It

- **The classic prank:** leave it running on a friend's laptop and tell them you are "just checking something" while you type furiously.
- **Film and video:** a convincing screen for a hacker scene, recorded with autopilot running so the actor's hands can do anything.
- **Streams and parties:** a background for a tech-themed stream or a cyberpunk party, ideally with the Matrix Green theme.
- **Classroom openers:** start a lesson on programming or cybersecurity with the screen everyone recognizes from films, then show what real code and real security work look like.

## Making the Scene Convincing

Close every other window, so only the editor is visible, and pick the Matrix Green or Amber Terminal theme in a dark room for the most cinematic look. Type in bursts rather than at a steady pace: real programmers pause to think, and so do film hackers just before the "Access Granted" moment. When recording, use autopilot and film over the actor's shoulder so their hands and the scrolling code are both in shot.

## What Real Hacking Looks Like

Real security work is slower and quieter than the movies. Penetration testers, the professionals companies hire to find weaknesses, spend most of their time reading documentation, scanning systems with specialist tools, and writing careful reports, always with written permission from the system's owner. Typing fast has nothing to do with it. If the hacker typer sparks real interest, legal practice platforms and capture-the-flag competitions are the place to learn.
