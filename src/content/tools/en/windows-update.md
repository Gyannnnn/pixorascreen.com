## How to Set Up the Fake Update

The fake Windows update screen recreates the full-screen message every Windows user knows: a spinning ring of dots, "Working on updates", a percentage, and the warning "Don't turn off your computer". On a laptop or desktop in fullscreen, it looks exactly like a PC that is busy updating.

1. Open the settings and choose a **Theme**: Windows 11 Blue, Dark Update, or Light Update.
2. Choose a **Mode** and, if needed, a **Duration** or **Speed** (1 to 10).
3. Pick a **Scenario** to set the status messages.
4. Press <kbd>F</kbd> for fullscreen. Press <kbd>Space</kbd> at any time to freeze or resume the progress.
5. Press <kbd>Esc</kbd> to end it.

## The Four Modes

| Mode | What the progress does | Best for |
|---|---|---|
| Realistic | Climbs with random stalls and bursts, like a real update | Convincing pranks |
| Timer | Reaches 100% over 5, 10, 15, or 30 minutes or 1 hour | Breaks, lunch, end-of-day jokes |
| Manual | Follows the Progress slider from 0 to 100 | Videos where you need an exact number |
| Infinite | Slows down near the end and never finishes | The classic never-ending update prank |

## Scenarios

The five scenarios change what the status line says while the update runs. **Security Update** downloads security intelligence and applies patches; **Feature Update** installs a new version of Windows; **Cumulative Update** works through numbered update packages; **Driver Update** installs device drivers; and **Insider Preview** mimics a test build. The variety stops the screen from repeating the same line and makes the update feel genuine.

## Beyond Pranks

- **Video production:** a clean update screen for a sketch or a tutorial, with Manual mode to hit an exact percentage on cue.
- **A visible break:** a monitor showing an update makes it obvious the computer is not available for a few minutes, a light-hearted way to signal you are away from your desk.
- **IT training:** show new staff what a normal update looks like, and that it should be left alone rather than switched off.

## If a Real Update Is Stuck

Real Windows updates can sit on one percentage for a long time, especially large feature updates on older hard drives. Wait at least an hour, ideally two, before acting. If the percentage has not moved and the disk activity light is idle, hold the power button for ten seconds to restart. Windows will usually either complete the update or undo it. If it keeps failing, run the Windows Update troubleshooter from Settings, System, Troubleshoot.
