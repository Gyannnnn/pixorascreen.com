## Como a pegadinha do travamento do Windows XP funciona

Para quem usou um PC nos anos 2000, a sequência é reconhecível na hora: um programa trava, aparece uma caixa de erro, mais caixas de erro se acumulam pela área de trabalho e então a tela inteira fica azul com linhas de texto branco. Esta página reproduz essa sequência numa área de trabalho do Windows XP recriada, com o botão verde Iniciar, o papel de parede no estilo Bliss e os ícones de Meu computador, Meus documentos, Internet Explorer e Lixeira.

1. Abra as configurações e escolha o que acontece ao iniciar: **Diálogo de erro → Cascata → Tela azul** para a sequência completa, ou **Tela azul imediata** para pular direto para a tela azul.
2. Escolha um **Atraso da tela azul** de 5, 12, 20 ou 30 segundos.
3. Escolha **Sino de aviso do XP** para ter som, ou **Sem som**.
4. Pressione <kbd>F</kbd> para ativar a tela cheia e deixe rodar.
5. Pressione <kbd>Esc</kbd> para encerrar.

## Por que as janelas de erro caem “em cascata”

Nos PCs de verdade com XP, quando o explorer.exe, o programa que desenha a barra de tarefas e a área de trabalho, travava, a tela podia parar de se redesenhar direito. Arrastar uma caixa de erro deixava então um rastro de cópias para trás, como se a janela estivesse sendo carimbada pela tela. As janelas em cascata desta página recriam esse famoso defeito gráfico, que virou uma das imagens mais conhecidas de um computador tendo um dia péssimo.

## A tela azul clássica

Antes do Windows 8, a tela azul da morte era só texto: um aviso de que “foi detectado um problema e o Windows foi desligado para evitar danos ao computador”, conselhos para verificar hardware ou software novos e um código STOP em hexadecimal para os técnicos. Ela assustava justamente porque explicava muito pouco. A versão moderna, com a carinha triste e o QR code, é recriada pela [pegadinha da tela azul](tool:blue-screen-prank), que combina melhor com os PCs atuais com Windows 10 e 11.

## Para quem essa pegadinha funciona

O travamento do XP funciona melhor com quem se lembra do XP: uma noite de jogos retrô, uma live para um público nostálgico, uma aula de história da computação ou uma brincadeira de escritório entre colegas que passaram o começo da carreira usando XP. Com alguém que só usou Windows 10 ou 11, a tela azul moderna é mais convincente.

Como em qualquer erro falso, revele a brincadeira rápido e nunca a use para pressionar alguém a ligar para um número ou pagar por um “conserto”. Para outras pegadinhas com cara retrô, experimente o [Hacker Typer](tool:hacker-typer) ou a [tela falsa de atualização do Windows](tool:windows-update).
