## Como o Hacker Typer funciona

O Hacker Typer parece um editor de código num quarto escuro. Aperte qualquer tecla, ou várias ao acaso se quiser, e linhas de código com cara de sério aparecem na tela como se você estivesse escrevendo numa velocidade sobre-humana. É a tela por trás de todo hacker de filme, transformada em algo que você controla.

1. Pressione <kbd>F</kbd> para ativar a tela cheia. O editor preenche o display e o navegador some.
2. Digite qualquer coisa. Cada tecla acrescenta os próximos caracteres do arquivo de código atual.
3. Pressione <kbd>1</kbd>, <kbd>2</kbd> ou <kbd>3</kbd> para alternar entre três arquivos: `cve_exploit.c`, `sniffer.py` e `brute_force.go`.
4. Pressione <kbd>Tab</kbd> ou <kbd>Enter</kbd> para o final: uma mensagem de “Acesso concedido” na tela.
5. Pressione <kbd>Esc</kbd> para parar.

## Configurações

Fora da tela cheia, as opções acima do editor permitem moldar o efeito:

- **Tema:** VS Code escuro, Monokai retrô, Terminal âmbar ou Verde Matrix.
- **Velocidade:** de 1 a 15 caracteres por tecla.
- **Interruptor MX:** o som de cada tecla: Interruptor azul, Interruptor marrom, Máquina de escrever ou Sem som.

Em tela cheia, <kbd>A</kbd> liga o piloto automático para o código se digitar sozinho, e <kbd>S</kbd> liga ou desliga o som do teclado.

## Ideias de uso

- **A pegadinha clássica:** deixe aberto no notebook de um amigo e diga que você está “só conferindo uma coisa” enquanto digita feito louco.
- **Cinema e vídeo:** uma tela convincente para uma cena de hacker, gravada com o piloto automático ligado para as mãos do ator ficarem livres.
- **Lives e festas:** um fundo para uma live de tecnologia ou uma festa cyberpunk, de preferência com o tema Verde Matrix.
- **Abertura de aulas:** comece uma aula de programação ou cibersegurança com a tela que todo mundo conhece dos filmes e depois mostre como são o código de verdade e o trabalho real de segurança.

## Deixando a cena convincente

Feche todas as outras janelas, para só o editor aparecer, e escolha o tema Verde Matrix ou Terminal âmbar num ambiente escuro para o visual mais cinematográfico. Digite em rajadas, não num ritmo constante: programadores de verdade param para pensar, e os hackers de filme também, logo antes do momento do “Acesso concedido”. Na hora de gravar, use o piloto automático e filme por cima do ombro do ator, para as mãos e o código rolando aparecerem juntos.

## Como é o hacking de verdade

O trabalho real de segurança é mais lento e silencioso do que nos filmes. Os pentesters, profissionais que as empresas contratam para encontrar falhas, passam a maior parte do tempo lendo documentação, analisando sistemas com ferramentas especializadas e escrevendo relatórios cuidadosos, sempre com permissão por escrito do dono do sistema. Digitar rápido não tem nada a ver com isso. Se o Hacker Typer despertar um interesse de verdade, plataformas de prática legais e competições de capture the flag (CTF) são o lugar para aprender.

Para outro tipo de drama no computador, a [tela Matrix](tool:matrix-screen) enche a tela de código caindo, a [tela de vírus falso](tool:fake-virus-screen) mostra alertas de segurança de mentira, e a [tela de radar](tool:radar-screen) parece o display de uma sala de controle.
