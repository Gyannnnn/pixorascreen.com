## Comment fonctionne Hacker Typer

Hacker Typer ressemble à un éditeur de code dans une pièce sombre. Appuyez sur n’importe quelles touches, tapez au hasard si vous voulez, et des lignes de code à l’air sérieux s’affichent à l’écran comme si vous les écriviez à une vitesse surhumaine. C’est l’écran qu’on voit derrière tous les hackers de cinéma, transformé en quelque chose que vous pouvez piloter.

1. Appuyez sur <kbd>F</kbd> pour passer en plein écran. L’éditeur remplit l’affichage et le navigateur disparaît.
2. Tapez n’importe quoi. Chaque touche ajoute les caractères suivants du fichier de code en cours.
3. Appuyez sur <kbd>1</kbd>, <kbd>2</kbd> ou <kbd>3</kbd> pour passer d’un des trois fichiers à l’autre : `cve_exploit.c`, `sniffer.py` et `brute_force.go`.
4. Appuyez sur <kbd>Tab</kbd> ou <kbd>Entrée</kbd> pour le final : un message « Accès autorisé » à l’écran.
5. Appuyez sur <kbd>Échap</kbd> pour arrêter.

## Réglages

Hors du plein écran, les réglages au-dessus de l’éditeur permettent de façonner l’effet :

- **Thème :** VS Code sombre, Monokai rétro, Terminal ambre ou Vert Matrix.
- **Vitesse :** de 1 à 15 caractères par touche.
- **Interrupteur MX :** le son de chaque touche : Interrupteur bleu, Interrupteur marron, Machine à écrire ou Muet.

En plein écran, <kbd>A</kbd> lance le pilote automatique pour que le code se tape tout seul, et <kbd>S</kbd> active ou coupe le son du clavier.

## Idées d’utilisation

- **La farce classique :** laissez-le tourner sur le portable d’un ami et dites-lui que vous « vérifiez juste un truc » en tapant frénétiquement.
- **Cinéma et vidéo :** un écran crédible pour une scène de piratage, filmé avec le pilote automatique pour que les mains de l’acteur restent libres.
- **Streams et fêtes :** un fond pour un stream tech ou une soirée cyberpunk, idéalement avec le thème Vert Matrix.
- **Ouverture de cours :** commencez un cours de programmation ou de cybersécurité avec l’écran que tout le monde connaît des films, puis montrez à quoi ressemblent le vrai code et le vrai travail de sécurité.

## Rendre la scène crédible

Fermez toutes les autres fenêtres, pour que seul l’éditeur soit visible, et choisissez le thème Vert Matrix ou Terminal ambre dans une pièce sombre pour le rendu le plus cinématographique. Tapez par rafales plutôt qu’à un rythme régulier : les vrais programmeurs s’arrêtent pour réfléchir, et les hackers de cinéma aussi, juste avant le moment « Accès autorisé ». Pour filmer, utilisez le pilote automatique et cadrez par-dessus l’épaule de l’acteur pour avoir à la fois ses mains et le code qui défile.

## À quoi ressemble le vrai piratage

Le vrai travail de sécurité est plus lent et plus discret qu’au cinéma. Les pentesteurs, ces professionnels que les entreprises engagent pour trouver les failles, passent l’essentiel de leur temps à lire de la documentation, à analyser des systèmes avec des outils spécialisés et à rédiger des rapports soignés, toujours avec l’autorisation écrite du propriétaire du système. Taper vite n’y est pour rien. Si Hacker Typer éveille un vrai intérêt, les plateformes d’entraînement légales et les compétitions de capture the flag (CTF) sont le bon endroit pour apprendre.

Pour un autre genre de drame informatique, l’[écran Matrix](tool:matrix-screen) remplit l’écran de code qui tombe, le [faux écran de virus](tool:fake-virus-screen) affiche de fausses alertes de sécurité, et l’[écran radar](tool:radar-screen) ressemble à l’affichage d’une salle de contrôle.
