## Ubuntu の起動画面

Ubuntu は最も人気のある Linux ディストリビューションのひとつで、長年その起動画面はこんな見た目でした。深いオーベルジーンの背景の中央に白い Ubuntu のロゴタイプがあり、その下に並んだ5つの点が、システムの読み込み中に1つずつ光っていきます。このページは、その起動画面を全画面で再現します。

1. <kbd>F</kbd>キーか、隅のボタンを押して画面いっぱいに表示します。
2. マウスを動かさずにおくと、2秒でポインターが消えます。
3. <kbd>Esc</kbd>キーで全画面表示を終了します。

本物の起動画面にも設定はないので、変更できる項目はありません。システムの準備ができるまで、点を光らせながらただ待つだけです。

## 使い方のアイデア

- **コンピューター室でのいたずら：** Linux のパソコンが並ぶ教室やオフィスなら、いつまでも終わらない起動画面はちょっとしたジョークになります。
- **動画や映画：** Linux ユーザー、サーバールーム、ハッカーが出てくるシーンで、「パソコンが起動中」の場面を本物らしく見せられます。
- **授業：** 初めて Ubuntu をインストールしたときに多くの人が目にするこの画面で、クラスに Linux を紹介しましょう。
- **懐かしさ：** 長く Ubuntu を使っている人なら、2010年代のバージョンの点に見覚えがあるはずです。

## ブラウザーを完全に隠す

全画面表示にすればたいていのシステムでブラウザーは隠れますが、コンピューター室や長時間つけておく画面なら、キオスクモードのほうがさらにすっきりします。Linux では、Chromium か Google Chrome を `--kiosk` オプションとこのページのアドレスを付けて起動すると、タブ、アドレスバー、閉じるボタンのない状態で起動画面が画面全体に表示されます。閉じるときは <kbd>Alt</kbd> + <kbd>F4</kbd> を押します。Firefox では <kbd>F11</kbd>キーで同じような全画面表示になります。

## 本物の Ubuntu の起動画面の裏で起きていること

本物のシステムでは、起動画面は Plymouth というプログラムが描いていて、Linux の起動中に出力される文字のメッセージを覆い隠しています。その裏ではカーネルが読み込まれ、ドライバーがハードウェアを認識し、数十ものサービスが起動します。Ubuntu の更新はふつう作業を続けている間にインストールされますが、カーネルの更新などの一部は、次の再起動時にこの同じ画面の裏で完了します。

本物の Ubuntu パソコンが起動画面で止まってしまったように見えるときは、次のようにします。

1. <kbd>Esc</kbd>キーで文字の起動ログに切り替え、どの処理で待っているかを確認します。
2. ディスクのチェックやネットワーク サービスが表示されているなら、数分待ちましょう。どちらも時間がかかることがあります。
3. いつまでも進まないなら再起動して GRUB メニューを開き（古い BIOS のパソコンでは <kbd>Shift</kbd>キーを押したまま、UEFI のパソコンでは <kbd>Esc</kbd>キーを何度か押します）、詳細オプションを選んで、古いカーネルかリカバリーモードで起動します。

ほかの偽のシステム画面なら、[偽のWindowsアップデート画面](tool:windows-update)と[macOSアップデート](tool:macos-screen)で進行状況、タイマー、シナリオを使え、[Androidアップデート画面](tool:android-update)ではスマホの更新を再現できます。
