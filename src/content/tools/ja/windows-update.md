## 偽のアップデートの準備

偽のWindowsアップデート画面は、Windows ユーザーなら誰もが知っている全画面のメッセージを再現します。回転する点の輪、「更新プログラムを構成しています」、パーセント、そして「コンピューターの電源を切らないでください」という警告です。ノートPCやデスクトップPCで全画面にすれば、まさに更新中の PC そのものに見えます。

1. 設定を開き、**テーマ**を選びます。Windows 11 ブルー、ダーク、ライトがあります。
2. **モード**を選び、必要に応じて**時間**または**速度**（1〜10）を設定します。
3. **シナリオ**を選んで、ステータスメッセージを決めます。
4. <kbd>F</kbd>キーで全画面表示にします。<kbd>Space</kbd>キーでいつでも進行を止めたり再開したりできます。
5. <kbd>Esc</kbd>キーで終了します。

## 4つのモード

| モード | 進行状況の動き | 向いている用途 |
|---|---|---|
| リアル | 本物の更新のように、ランダムに止まったり急に進んだりしながら上がる | 本物らしいいたずら |
| タイマー | 5、10、15、30分または1時間で100%に達する | 休憩、昼休み、終業前のジョーク |
| 手動 | 「進行状況」スライダーに合わせて0〜100まで動く | 正確な数字が必要な動画 |
| 無限 | 終わりに近づくと遅くなり、決して終わらない | 定番の終わらないアップデートのいたずら |

## シナリオ

5つのシナリオで、更新中にステータス行に表示される内容が変わります。**セキュリティ更新プログラム**はセキュリティ インテリジェンスをダウンロードして修正プログラムを適用し、**機能更新プログラム**は Windows の新しいバージョンをインストールし、**累積更新プログラム**は番号付きの更新パッケージを順に処理し、**ドライバー更新プログラム**はデバイス ドライバーをインストールし、**Insider Preview ビルド**はテストビルドをまねます。表示が変わるので画面が同じ行を繰り返さず、更新が本物らしく感じられます。

## いたずら以外の使い道

- **動画制作：** 寸劇やチュートリアル用のきれいな更新画面に。手動モードなら、狙ったタイミングで正確なパーセントを表示できます。
- **目に見える休憩：** 更新中のモニターは、数分間パソコンが使えないことをはっきり伝えます。席を外していることを示す、ちょっとしゃれた方法です。
- **IT研修：** 新しいスタッフに、普通の更新がどう見えるか、電源を切らずに終わるまで待つべきだということを見せられます。

## 本物の更新が止まってしまったら

本物の Windows Update は、特に古いハードディスクでの大きな機能更新では、同じパーセントのまま長く止まることがあります。何かする前に、少なくとも1時間、できれば2時間は待ちましょう。パーセントが動かず、ディスクのアクセスランプも点滅していなければ、電源ボタンを10秒長押しして再起動します。Windows はたいてい、更新を完了するか元に戻します。何度も失敗する場合は、[設定] > [システム] > [トラブルシューティング] から Windows Update のトラブルシューティング ツールを実行してください。

ほかの偽のシステム画面なら、Windows のクラッシュを表示する[ブルースクリーンのいたずら](tool:blue-screen-prank)、Mac が更新をインストールする様子をまねる[macOSアップデート](tool:macos-screen)、2000年代を呼び戻す[Windows XPクラッシュ](tool:windows-xp-crash)の画面もどうぞ。
