## ブルースクリーンのいたずらの準備

このページは、Windowsが重大なエラーの後に表示するクラッシュ画面を再現します。大きな悲しい顔、「問題が発生したため、PC を再起動する必要があります」というメッセージ、100まで増えていくパーセンテージ、QRコード、停止コードです。すべてブラウザーのタブ内で動作するため、見た目はクラッシュでも、裏ではパソコンが普段どおり動き続けています。

1. 使いたいパソコン、できればWindowsのノートPCかデスクトップでこのページを開きます。
2. プレビューの隅にある歯車アイコンをクリックします。**時間**でカウントが100%に達するまでの時間を5〜180秒の範囲で設定し、途中から始めたい場合は**開始時のパーセンテージ**を設定します。
3. 設定パネルを閉じ、<kbd>F</kbd>キーか全画面ボタンを押します。ブラウザーのタブとアドレスバーが消え、カウントが始まります。
4. マウスポインターを画面の端に移動して、そのままにしておきます。
5. いたずらがうまくいったら、<kbd>Esc</kbd>キーを押して終了します。

パーセンテージは一定の速さでは増えません。本物の画面と同じように、ランダムなところで1〜2秒止まってから進むので、本物らしく見えます。停止コードはページを読み込むたびに新しく選ばれます。

## 停止コードの意味

このページの8種類の停止コードは、実際のWindowsのエラーです。本物のクラッシュでこれらが表示された場合、おおよそ次のことを示しています。

| 停止コード | 主な意味 |
|---|---|
| CRITICAL_PROCESS_DIED | Windowsの動作に欠かせないプロセスが予期せず停止した |
| SYSTEM_SERVICE_EXCEPTION | システムサービスやドライバーが処理できないエラーに遭遇した |
| MEMORY_MANAGEMENT | RAMの故障やドライバーが原因で、Windowsがメモリエラーを検出した |
| IRQL_NOT_LESS_OR_EQUAL | ドライバーが、その時点でアクセスを許されていないメモリにアクセスした |
| DRIVER_IRQL_NOT_LESS_OR_EQUAL | 同じ不具合で、原因が特定のドライバーまで突き止められたもの |
| KMODE_EXCEPTION_NOT_HANDLED | カーネルモードで動作しているプログラムがクラッシュした |
| PAGE_FAULT_IN_NONPAGED_AREA | 存在しないメモリが参照された |
| BAD_POOL_HEADER | Windowsのメモリ管理情報が、多くはドライバーによって壊された |

## 本物のブルースクリーンが表示されたら

ドライバーやWindowsの更新後に一度だけブルースクリーンが出るのはよくあることで、その後二度と出ないことも多いです。停止コードを書き留め、PCを再起動させてから、保留中のWindowsとグラフィックドライバーの更新をインストールしましょう。同じコードが何度も表示される場合は、Microsoftのサポートサイトでそのコードを検索し、最近のハードウェアやドライバーの変更を元に戻し、コードがメモリに関するものならWindows メモリ診断を実行してください。ブルースクリーンでファイルが失われることはありません。パソコンが再起動するだけです。

## 責任を持って使うために

よいいたずらは、1〜2分以内にみんなが笑って終わるものです。すぐにネタばらしをして、タイミングも選びましょう。締め切りに追われている人や、保存していない作業があって慌ててしまいそうな人には使わないでください。偽のエラー画面を使って、誰かに電話番号へ電話させたり、「修理代」を払わせたり、何かをインストールさせたりすることは絶対にやめてください。それはサポート詐欺の手口で、本物のクラッシュ画面がそうしたことを求めることはありません。

## そのほかのクラッシュ画面とアップデート画面

古いPCなら、[Windows XPクラッシュ画面](tool:windows-xp-crash)で当時のexplorer.exeのエラーダイアログを再現できます。[偽のWindowsアップデート画面](tool:windows-update)は、いつまでも終わらないアップデートでじわじわ効くタイプです。[偽ウイルス画面](tool:fake-virus-screen)はクラッシュの代わりに偽のセキュリティ警告を表示し、[壊れた画面](tool:broken-screen)はディスプレイそのものが割れたように見せます。
