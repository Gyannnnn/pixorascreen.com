## 偽の macOS アップデートの準備

Mac がアップデートをインストールするとき、画面が暗くなり、中央に Apple のロゴが表示され、その下で細い進行バーが残り時間の目安とともにゆっくり伸びていきます。このページはその画面をブラウザーで再現するので、どの Mac でも、ほかのパソコンでも、macOS をインストールしているように見せられます。

1. 設定を開き、**テーマ**を選びます。macOS ダーク、macOS ライト、スペースグレイがあります。
2. **モード**を選びます。リアル、タイマー、手動、無限があります。
3. タイマーモードでは**時間**（5、10、15、30分または1時間）を、それ以外では**速度**（1〜10）を設定します。
4. ステータスメッセージ用に**シナリオ**を選びます。
5. <kbd>F</kbd>キーで全画面表示、<kbd>Space</kbd>キーで一時停止、<kbd>Esc</kbd>キーで終了します。

## 本物らしく見えるポイント

Mac のアップデートは静かでシンプルなので、細かな部分が大切です。進行バーは不規則に進み、「システムボリュームを確認中…」や「クリーンアップ中…」のような段階で長く止まり、残り時間の目安も「残り約15分…」から、なかなか終わらない「残り約1分…」まで途中で変わっていきます。リアルモードはこのリズムを再現しています。MacBook でダークテーマを全画面にすれば、ひと目では本物と見分けがつきません。

## シナリオ

| シナリオ | 表示されるメッセージ |
|---|---|
| macOSアップデート | 新しい macOS のバージョンの準備、インストール、完了 |
| セキュリティレスポンス | 修正プログラムに関する手順付きの、すばやいセキュリティ修正 |
| App Storeのアップデート | アプリの整合性の確認とアプリの更新 |
| ファームウェアアップデート | BridgeOS ファームウェアの確認と設定 |
| macOS ベータ | ベータ版の適用 |

## 使い方のアイデア

- **オフィスでのいたずら：** 同僚の Mac に1時間続くアップデートを表示しておき、Escキーをひと押ししてネタばらしをしましょう。
- **動画や舞台：** シーンに使える本物らしい Mac の画面です。手動モードなら進行状況を正確に設定できます。
- **授業：** 学生や新しいスタッフに、普通のアップデートがどんな見た目か、なぜ中断してはいけないのかを見せられます。
- **目に見える休憩：** 「アップデート中」の Mac は、数分間席を外していることをはっきり伝えます。

## 本物の Mac のアップデートが止まってしまったら

本物のアップデートは、「残り約1分…」のまま1分よりずっと長く止まることがあります。少なくとも1時間は待ちましょう。何も動かなければ、電源ボタンを10秒ほど長押ししてから、もう一度 Mac を起動します。たいていはインストーラーが続きから再開します。何度も失敗する場合は、macOS 復元で起動し（Appleシリコン搭載Macでは電源ボタンを長押し、Intel搭載Macでは起動時に Command-R を押します）、「macOS を再インストール」を選びましょう。ファイルとアプリはそのまま残ります。

ほかの偽のシステム画面なら、[偽のWindowsアップデート画面](tool:windows-update)、[Ubuntuアップデート](tool:ubuntu-screen)、[Androidアップデート画面](tool:android-update)も試してみてください。
