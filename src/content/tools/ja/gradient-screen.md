## 画面のバンディングを確認する方法

グラデーションは、ディスプレイがきれいに表示するのが最も難しい画像です。ピクセルの列ごとに少しずつ違う色が必要で、パネルや信号経路のどこかで手を抜くと、なめらかな変化が目に見える縞に変わってしまいます。このページでは、明るい青（`#007CF0`）からシアン（`#00DFD8`）へと変わる、斜めのグラデーションを表示します。

1. 夜間モード、ブルーライトカット、「ビビッド」などの画質モードやダイナミックコントラストをオフにします。
2. <kbd>F</kbd>キーで全画面表示にし、いつもの距離から画面を見ます。
3. グラデーションを横切るはっきりした縞と、ピンクや緑がかった縞がないか探します。
4. 次に、条件の厳しいグラデーションを試します。1つ目のスウォッチをクリックして`000000`、2つ目をクリックして`333333`と入力します。暗くてコントラストの低いグラデーションほど、バンディングは隠れにくくなります。

## 見え方の判断のしかた

8ビット信号では、各色チャンネルは256段階です。`#000000`から`#333333`へのグラデーションには両端の間に51段階しかないため、幅1920ピクセルの画面では1段がおよそ30〜40ピクセルの幅になり、よく見ればどの画面でも段差がわかります。これは計算上そうなるもので、故障ではありません。問題を疑うべきなのは次のような場合です。

- **段差が不均一**で、一部の帯がほかより極端に広い。
- **段差に色が付いて**いて、グレーのグラデーションにピンク、緑、紫の縞が出る。
- 本来なめらかな部分に**まだらなむら**があり、強い圧縮や画像処理のサインになっている。
- 同じ色で比べて、**ほかの画面よりはるかにバンディングが多い**。

## よくある原因と対処法

| 原因 | 試すこと |
|---|---|
| ディザリング付きの6ビットパネル | 低価格のノートPCやモニターに多く、直すものはありませんが、結果の説明にはなります |
| RGBリミテッドレンジ（16〜235） | パソコン用モニターなら、グラフィックドライバーの出力をフルレンジに設定します |
| 画質補正 | ダイナミックコントラスト、「ビビッド」モード、エッジ強調をオフにします |
| 誤ったカラープロファイル | モニターの色設定と、OSのディスプレイプロファイルをリセットします |
| 圧縮された動画や画像 | 配信動画やJPEGのバンディングは、画面ではなくファイルが原因です |

## グラデーション背景を作る

同じツールで、シンプルできれいなグラデーション壁紙も作れます。スウォッチをクリックしてそれぞれの色を選び、<kbd>R</kbd>キーでランダムな組み合わせにして、横向き、縦向き、正方形、またはお使いの画面の解像度でダウンロードします。青からシアン、オレンジからピンクのように隣り合う色相どうしのグラデーションは、反対色どうしのグラデーションよりなめらかでバンディングも出にくくなります。反対色どうしだと、途中でくすんだグレーを通るからです。単色が欲しいときは[カスタムカラー画面](tool:custom-color-screen)を、4色を並べて比べたいときは帯状に表示できる[HEX画面](tool:hex-screen)を使いましょう。

バンディングは、ディスプレイチェックのひとつにすぎません。欠けたピクセルは[6色のドット抜けテスト](tool:dead-pixel-test)で、明るさのむらは均一な[灰色の画面](tool:grey-screen)で最も見つけやすくなります。
