## どこでもつけられる暖炉の火

暖炉の画面は、ディスプレイを揺らめく炎と薪が燃える音で満たします。冬の夜の居心地のよい背景にも、集まりのときの華やかなテレビにも、暖炉のない部屋の温かな明かりにもなります。火をつけるものが何もないので、子ども部屋や賃貸の部屋でも安心してつけておけます。

1. <kbd>F</kbd>キーか全画面表示ボタンを押して、炎を画面いっぱいに表示します。
2. 歯車ボタン、または全画面表示中に<kbd>C</kbd>キーで**設定**を開き、炎を調整します。
3. 全画面表示中は、<kbd>M</kbd>キーではぜる音をミュートでき、矢印キーの<kbd>↑</kbd>と<kbd>↓</kbd>で音量を変えられます。
4. <kbd>Esc</kbd>キーで全画面表示を終了します。

## 炎を整える

| 設定 | 変わるもの |
|---|---|
| 炎の色 | クラシック、アンバー、ブルー、バイオレット、エメラルドの炎 |
| 炎の高さ | 低く落ち着いた火（60%）から高く燃え上がる炎（160%）まで |
| 光の強さ | 炎が周りをどれだけ明るく照らすか |
| 薪のはぜる音 | 音の中で薪がはぜてパチパチ鳴る頻度 |
| 音量 | 火の音全体の大きさ |
| スリープタイマー | オフ、15、30、60、90分 |

いちばん本物らしく見せるには、クラシックかアンバーを選び、炎の高さを最大より少し低めにして、部屋の照明を落としましょう。画面の光が壁に映り込みます。

## テレビに映す

暖炉を置くなら、やはりテレビです。映す方法は簡単に3つあります。

- **テレビのブラウザー：** ほとんどのスマートテレビにはWebブラウザーがあります。そこでページを開き、全画面表示を押しましょう。
- **ノートPCからHDMI：** つないで画面をミラーリングまたは拡張し、テレビでページを全画面表示にします。
- **キャスト：** Chromeの「キャスト」で、タブをChromecastやキャスト機能内蔵のテレビに送ります。

テレビの明るさは控えめにしましょう。部屋でいちばん明るいものでないほうが、炎は温かく自然に見えます。

## テレビの伝統

テレビに暖炉の火を映す習慣は、インターネットよりも古いものです。1966年、ニューヨークのテレビ局WPIXが、暖炉のない視聴者にも楽しんでもらおうと、クリスマスイブに燃える薪を放送しました。この「ユールログ」はクリスマスの恒例となり、その後もテレビ局や動画配信サービスがまねを続けています。このページは、好きなように調整して、いつまでも燃やしておける火で、その伝統を受け継いでいます。

ほかの落ち着いたシーンなら、窓を打つ雨の[雨の画面](tool:rain-screen)、やさしく降る雪の[雪の画面](tool:snow-screen)、魚が泳ぐ水槽の[アクアリウム画面](tool:aquarium-screen)もどうぞ。炎のない、静かで温かな明かりがほしいなら、[茶色の画面](tool:brown-screen)を試してみてください。
