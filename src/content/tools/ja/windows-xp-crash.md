## Windows XP クラッシュのいたずらのしくみ

2000年代にパソコンを使っていた人なら、この流れはひと目でわかるはずです。プログラムが固まり、エラーの小窓が現れ、デスクトップにエラーの小窓がどんどん重なり、最後に画面全体が白い文字の並ぶ青一色になります。このページは、緑のスタートボタン、Bliss 風の壁紙、マイ コンピュータ、マイ ドキュメント、Internet Explorer、ごみ箱のアイコンを再現した Windows XP のデスクトップで、この流れを再生します。

1. 設定を開いて、開始時の動作を選びます。一連の流れを見せるなら **エラーダイアログ → 連鎖 → ブルースクリーン**、いきなりブルースクリーンにするなら **すぐにブルースクリーン** です。
2. **ブルースクリーンまでの時間**を5、12、20、30秒から選びます。
3. 音を鳴らすなら **XP の警告音**、鳴らさないなら **ミュート** を選びます。
4. <kbd>F</kbd>キーで全画面表示にして、そのまま流します。
5. <kbd>Esc</kbd>キーで終了します。

## エラーウィンドウが「連鎖」する理由

本物の XP パソコンでは、タスクバーとデスクトップを描画するプログラムである explorer.exe がクラッシュすると、画面が正しく再描画されなくなることがありました。そこでエラーの小窓をドラッグすると、まるでウィンドウを画面にスタンプしていくように、後ろにコピーの跡が残ったのです。このページの連鎖するダイアログはその有名な表示の不具合を再現したもので、とんでもなくついていない一日を過ごすパソコンを象徴する、誰もが知る光景になりました。

## 定番のブルースクリーン

Windows 8 より前のブルースクリーンは文字だけでした。「問題が検出されたため、コンピュータへの損傷を防ぐために Windows をシャットダウンしました」という警告、新しいハードウェアやソフトウェアを確認するようにというアドバイス、技術者向けの16進数の STOP コードです。ほとんど何も説明してくれないからこそ、威圧感がありました。悲しい顔の絵文字と QR コードの付いた現代版は、Windows 10 や 11 の今のパソコンによく合う[ブルースクリーンのいたずら](tool:blue-screen-prank)で再現しています。

## このいたずらが向いている相手

XP のクラッシュがいちばん効くのは、XP を覚えている人です。レトロゲームの夜、懐かしさを求める視聴者向けの配信、コンピューターの歴史の授業、社会人になりたての頃を XP で過ごした同僚どうしのオフィスジョークなどにぴったりです。Windows 10 や 11 しか使ったことのない人には、現代版のブルースクリーンのほうが本物らしく見えます。

偽のエラーを使うときは必ず、すぐにネタばらしをしましょう。電話をかけさせたり、「修理代」を払わせたりするために使うのは絶対にやめてください。ほかのレトロないたずらなら、[ハッカータイパー](tool:hacker-typer)や[偽のWindowsアップデート画面](tool:windows-update)を試してみてください。
