## Cómo funciona Hacker Typer

Hacker Typer parece un editor de código en una habitación oscura. Presiona cualquier tecla, apriétalas al azar si quieres, y aparecerán en la pantalla líneas de código de aspecto serio, como si las escribieras a una velocidad sobrehumana. Es la pantalla que hay detrás de todo hacker de película, convertida en algo que puedes controlar.

1. Presiona <kbd>F</kbd> para ver en pantalla completa. El editor llena la pantalla y el navegador desaparece.
2. Escribe cualquier cosa. Cada tecla agrega los siguientes caracteres del archivo de código actual.
3. Presiona <kbd>1</kbd>, <kbd>2</kbd> o <kbd>3</kbd> para cambiar entre tres archivos: `cve_exploit.c`, `sniffer.py` y `brute_force.go`.
4. Presiona <kbd>Tab</kbd> o <kbd>Enter</kbd> para el final: un mensaje de “Acceso concedido” en pantalla.
5. Presiona <kbd>Esc</kbd> para terminar.

## Configuración

Fuera de la pantalla completa, los ajustes sobre el editor te permiten dar forma al efecto:

- **Tema:** VS Code oscuro, Monokai retro, Terminal ámbar o Verde Matrix.
- **Velocidad:** de 1 a 15 caracteres por tecla.
- **Interruptor MX:** el sonido de cada tecla: Interruptor azul, Interruptor marrón, Máquina de escribir o Silenciado.

A pantalla completa, <kbd>A</kbd> activa el piloto automático para que el código se escriba solo, y <kbd>S</kbd> activa o desactiva el sonido del teclado.

## Ideas para usarlo

- **La broma clásica:** déjalo abierto en la laptop de un amigo y dile que “solo estás revisando algo” mientras escribes como loco.
- **Cine y video:** una pantalla convincente para una escena de hackers, grabada con el piloto automático activado para que las manos del actor puedan hacer cualquier cosa.
- **Streams y fiestas:** un fondo para un stream de tecnología o una fiesta cyberpunk, idealmente con el tema Verde Matrix.
- **Inicio de clases:** empieza una clase de programación o ciberseguridad con la pantalla que todos reconocen de las películas y luego muestra cómo se ven el código real y el trabajo real de seguridad.

## Cómo hacer que la escena sea convincente

Cierra todas las demás ventanas, para que solo se vea el editor, y elige el tema Verde Matrix o Terminal ámbar en una habitación oscura para el aspecto más cinematográfico. Escribe a ráfagas y no a un ritmo constante: los programadores reales se detienen a pensar, y los hackers de película también, justo antes del momento de “Acceso concedido”. Al grabar, usa el piloto automático y filma por encima del hombro del actor para que sus manos y el código que avanza salgan en la toma.

## Cómo es el hackeo real

El trabajo real de seguridad es más lento y silencioso que en las películas. Los pentesters, los profesionales que las empresas contratan para encontrar debilidades, pasan la mayor parte del tiempo leyendo documentación, analizando sistemas con herramientas especializadas y escribiendo informes cuidadosos, siempre con permiso por escrito del dueño del sistema. Escribir rápido no tiene nada que ver. Si Hacker Typer te despierta un interés real, las plataformas de práctica legales y las competencias de capture the flag (CTF) son el lugar para aprender.

Para otro tipo de drama informático, la [pantalla Matrix](tool:matrix-screen) llena la pantalla de código que cae, la [pantalla de virus falso](tool:fake-virus-screen) muestra advertencias de seguridad de mentira y la [pantalla de radar](tool:radar-screen) parece la pantalla de una sala de control.
