## Cómo funciona la broma del fallo de Windows XP

Para cualquiera que haya usado una PC en los años 2000, la secuencia se reconoce al instante: un programa se congela, aparece un cuadro de error, se acumulan más cuadros de error por el escritorio y luego toda la pantalla se vuelve azul con líneas de texto blanco. Esta página reproduce esa secuencia en un escritorio de Windows XP recreado, con el botón verde de Inicio, el fondo al estilo Bliss y los íconos de Mi PC, Mis documentos, Internet Explorer y la Papelera de reciclaje.

1. Abre la configuración y elige qué pasa al iniciar: **Diálogo de error → Cascada → Pantallazo azul** para la secuencia completa, o **Pantallazo azul inmediato** para saltar directo a la pantalla azul.
2. Elige una **Espera del pantallazo azul** de 5, 12, 20 o 30 segundos.
3. Elige **Campana de advertencia de XP** para tener sonido, o **Silenciado**.
4. Presiona <kbd>F</kbd> para ver en pantalla completa y déjalo correr.
5. Presiona <kbd>Esc</kbd> para terminar.

## Por qué las ventanas de error caen “en cascada”

En las PC reales con XP, cuando fallaba explorer.exe, el programa que dibuja la barra de tareas y el escritorio, la pantalla podía dejar de redibujarse bien. Arrastrar un cuadro de error dejaba entonces un rastro de copias detrás, como si la ventana se fuera estampando por la pantalla. Los diálogos en cascada de esta página recrean ese famoso fallo gráfico, que se convirtió en una de las imágenes más reconocibles de una computadora teniendo un día muy malo.

## El pantallazo azul clásico

Antes de Windows 8, el pantallazo azul era solo texto: un aviso de que “se ha detectado un problema y se ha apagado Windows para evitar daños al equipo”, consejos para revisar el hardware o el software nuevo y un código STOP en hexadecimal para los técnicos. Intimidaba justamente porque explicaba muy poco. La versión moderna, con su carita triste y su código QR, la recrea la [broma de pantalla azul](tool:blue-screen-prank), que encaja mejor con las PC actuales con Windows 10 y 11.

## A quién le va esta broma

El fallo de XP funciona mejor con gente que recuerda XP: una noche de juegos retro, un stream para un público nostálgico, una clase de historia de la computación o una broma de oficina entre colegas que pasaron sus primeros años de trabajo con XP. Con alguien que solo ha usado Windows 10 u 11, el pantallazo azul moderno resulta más convincente.

Como con cualquier error falso, revela la broma rápido y nunca la uses para presionar a alguien a llamar a un número o pagar por un “arreglo”. Para otras bromas de estilo retro, prueba [Hacker Typer](tool:hacker-typer) o la [pantalla falsa de actualización de Windows](tool:windows-update).
